## Verwendung auf der FAT32-Karte

Die mitgelieferten Dateien `PACMAN.COM`, `KIKSTART.COM` und `PUNIVERS.COM` besitzen bereits den benötigten 9-Byte-Z1013-Kopf. Sie können unverändert in das Wurzelverzeichnis der FAT32-Karte kopiert werden. Das Werkzeug `@DS` ist nur für rohe Programmdateien ohne Kopf vorgesehen.

## Using the FAT32 card

The supplied `PACMAN.COM`, `KIKSTART.COM`, and `PUNIVERS.COM` files already contain the required 9-byte Z1013 header. Copy them unchanged to the root directory of the FAT32 card. The `@DS` tool is intended only for raw program files that do not yet have a header.
